# UI notes

- Palette: white and cool-grey surfaces, navy (`navy-900` #0B1B33) for structure, blue (`brand-600` #1D54CC) for actions.
- Typeface: Manrope throughout, with tabular numerals for IDs, counts and dates.
- Status colors are consistent everywhere: Submitted grey-blue, Assigned blue, In Progress amber, Resolved green.
- Priority colors: Low grey, Medium sky, High orange, Critical red.
- The progress tracker on each complaint (Submitted, Assigned, In Progress, Resolved) is the signature element.
- Reusable pieces: `components/ui/` (buttons, fields, modal, badges, stat cards, empty states, charts) and `components/complaints/` (table, tracker, timeline).
